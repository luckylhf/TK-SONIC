# Security Policy

## Reporting a Vulnerability

If you believe you have found a security vulnerability in this downstream
TienKung2 Pro package, report it privately through the security or support channel
supplied by the distributor from which you received the package. Do not publish
exploit details in a public issue.

NVIDIA's product-security channels apply to NVIDIA products and upstream NVIDIA
code, not to downstream TienKung2 Pro modifications. If investigation shows that a
report concerns unmodified NVIDIA upstream code, follow NVIDIA's coordinated
vulnerability disclosure process at https://www.nvidia.com/en-us/security/.
